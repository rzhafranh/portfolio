# Portfolio Design Direction

## Identity

An editorial project archive built around real work. The interface should feel precise, curious, and personal rather than like a generic developer landing page.

## Visual Language

- Core surfaces: warm off-white in light mode and charcoal in dark mode.
- Accent: teal, used for links, focus, and the most important action.
- Typography: Plus Jakarta Sans for its clear contemporary shapes and readable dense project descriptions.
- Motif: numbered sections, crisp rules, and large project imagery. These elements make the work itself the visual identity.
- Cards stay mostly flat. Borders separate content; shadows only mark temporary elevation such as the lightbox or audio panel.

## Composition

Project imagery leads. Supporting sections may use sticky labels, timelines, or asymmetric grids, but should not repeat the same heading-and-card composition throughout the page.

## Motion

Dial: ENERGY 2 / RHYTHM 3 / MOTION 2

Motion explains state changes and navigation. Nothing decorative loops indefinitely. Reduced-motion preferences remove nonessential movement.

## Decision Record

- Teal is the only chromatic accent so attention has a clear destination.
- Warm neutral surfaces keep photographs and interface screenshots visually accurate.
- Numbered headings create an editorial index tied to the portfolio's actual projects.
- Project cards vary in size to reflect importance instead of presenting every item as equal.
- Rounded pills are reserved for filters and compact metadata because their shape communicates selection or categorization.
